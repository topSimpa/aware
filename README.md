## Getting Started

### Prerequisites
1. git
2. Node.js

### Installation & Setup
1. Clone this repository:

   ```sh
   git clone <repo_url>
   cd commit
   ```

2. Install the necessary dependencies:

   ```sh
   npm install
   ```

3. Create a dist directory at the root of your project
   ```sh
   mkdir dist
   ```

4. Check `package.json` for other available commands.
